# 🍽️ BlackWhiteLog

> 맛집 리뷰와 기록을 관리할 수 있는 Flask 기반 웹사이트 프로젝트입니다.

---

## 📌 프로젝트 소개

BlackWhiteLog는 사용자가 맛집 정보를 등록하고, 리뷰를 작성하며, 음식점 정보를 관리할 수 있는 웹 서비스입니다.

---

## 🛠️ Tech Stack

| 분야 | 기술 |
|---|---|
| Frontend | HTML, CSS, JavaScript |
| Backend | Python, Flask |
| Database | SQLite |
| Template | Jinja2 |

---

## ✨ 주요 기능

- 맛집 정보 등록
- 맛집 리스트 조회
- 리뷰 작성
- 평점 관리
- 검색 기능
- 음식점 데이터 관리
